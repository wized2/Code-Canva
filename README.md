# Code Canva

Type-out code for **YouTube Shorts** — human-like typing, intro/outro cards, optional recording.

## Features

- Paste HTML / JS / Kotlin / Python / JSON
- Human typing cadence + blinking cursor + optional key sounds
- Customizable start & end cards (animations)
- Record intro → code → outro in one take
- Library: open / share / delete clips

## Build

```bash
./gradlew assembleRelease
```
