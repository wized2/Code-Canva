# Code Canva

**Type-out any code or HTML** in a sleek editor UI — syntax highlighting, live HTML preview, optional session recording.

![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

## Features

- Paste **HTML / JS / CSS**, Kotlin, Python, JSON, or plain text
- **Start** — types the source character-by-character, word-by-word, or line-by-line
- Adjustable **speed**, **font size**, language chips for highlighting
- **Run preview** — WebView for HTML (JS + CSS enabled)
- **Record** (optional) — system screen capture while typing; saves under Movies/CodeCanva

## Build

```bash
./gradlew assembleRelease
```

## Privacy

Recording uses Android’s MediaProjection dialog (user must approve). No accounts, no ads, offline editor.
